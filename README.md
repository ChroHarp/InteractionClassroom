# 平興數資・探索教室

像素教室全景、九個可互動的物件、榮譽榜與宣傳影片。場景參考平興國中的高斯、法拉第教室。

## 預覽

在專案根目錄執行 `python -m http.server 8765 --bind 127.0.0.1`，然後開啟 [classroom.html](http://127.0.0.1:8765/classroom.html)。

將滑鼠移到教室物件上會看到局部提亮與名稱。可用 Tab 選取物件，Enter 開啟，Escape 返回。窄螢幕提供四個視角和文字按鈕。選擇榮譽榜會從原位置推近。可用「減少動態」直接切換視角。

畫面底部的左右按鈕可在九個物件間循環。開啟物件後也可用左右方向鍵移動鏡頭。在同一次探索中離開再回到榮譽榜，會保留篩選。瀏覽器的上一頁會返回開始探索時的視角。

點「觸控螢幕」再按播放，即可在頁內觀看原網站的平興數資宣傳影片。離開觸控螢幕會停止影片。也可使用面板下方的 YouTube 連結。

空教室和各物件的透明 WebP 素材位於 `assets/classroom/room/`。物件位置以空景寬高的百分比設定，在 `assets/classroom/classroom.js` 的 `objects` 陣列調整。

榮譽榜預設顯示最新年度，可按年份、類別及關鍵字篩選。可用 `classroom.html#honors?year=2024` 直接開啟特定年份。
