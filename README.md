# 平興數資・探索教室

教室全景、八個物件熱點與榮譽榜特寫。場景以交接後補充的原始像素圖為基準。

## 預覽

在專案根目錄執行 `python -m http.server 8765 --bind 127.0.0.1`，然後開啟 [classroom.html](http://127.0.0.1:8765/classroom.html)。

將滑鼠移到教室物件上會看到局部提亮與名稱。可用 Tab 選取物件，Enter 開啟，Escape 返回。窄螢幕提供四個視角和文字按鈕。
