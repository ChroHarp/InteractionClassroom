# 探索教室｜單一 3D 場景設計

## 構圖與動線

以 `room/panorama.webp` 作為構圖與配色參考，**不從該圖擷取任何材質**。維持單一 Three.js 空間與連續相機，不使用正視／斜視圖片互相變形。

- 左牆：實體凹窗、窗台植物、實驗櫃與儀器；入口旁放 16:9 橫式教學螢幕。
- 後牆：銀框綠黑板、課程佈告欄；講桌在左後方。
- 中央：略縮小的八角共學桌，讓出走道。
- 前景：白色六角數學探索桌，向前移 0.6 m，使教具成為前景主體。
- 右牆：連續星空壁畫、榮譽木牌、活動示意畫框；下方放三色創客櫃。
- 天花：深色結構網格下方的綠／藍懸吊格柵，在水平面旋轉約 13.75°，斜向關係來自模型本身。

## 材質與模型分工

| 模組 | 職責 | 素材來源 |
| --- | --- | --- |
| `scene-3d.js` | 相機、熱點、按需渲染、共學桌、數學桌、黑板、教學螢幕 | 載入下列三個模組 |
| `scene-environment.js` | 牆板、窗框、門、戶外樹木、天花與地板 | 原生幾何與原創材質 |
| `scene-materials.js` | 統一配色、木地板、黑板、課程欄、入口牌、活動示意圖 | Canvas 正面繪製，無透視與烘入的家具背景 |
| `scene-props.js` | 實驗器材、三色櫃、幾何教具、榮譽牌、盆栽 | 幾何實體；標示使用 Canvas |
| `materials/solar-system.webp` | 單幅九星體壁畫 | 重新生成的平面插畫，每顆星體一次，無重複鋪排 |
| `materials/logo-2025.webp` | 螢幕 LOGO | 使用者提供的 `LOGO-2025.png`，只轉檔，保留完整比例 |
| `room/scene-fallback.jpg` | 載入中的靜態畫面 | 同一個最終 3D 場景截圖，不使用舊設計圖冒充實景 |

壁畫保留參考設計的九星體意象，包含冥王星；它是裝飾性歷史意象，不是現行行星分類教材。UV 只選取新素材中的星體橫帶，實體比例與 UV 比例一致，不讓圓形星體被拉扁。圖面沒有循環或鏡像貼圖。原始 PNG、生成提示見 `materials/README.md`。

### 器材與展示

- 實驗台：紫、青、綠、黃液體；中空燒杯、窄頸錐形瓶、四管試管架、夾持架、綠色加熱盤、水槽、水龍頭、顯微鏡。
- 創客櫃：外框、背板、層板與抽屜均分為薄荷綠／紫／藍三整列；上層為 3D 列印機、頂點連桿多面體、DNA 雙螺旋；中層為收納盒、彩色積木、線框角錐。櫃頂只有盆栽，沒有文字立牌。
- 螢幕：顯示區 `1.28 × 0.72 m`（16:9）；LOGO 在 `0.64 × 0.64 m` 區域完整呈現，右側為班級名稱。影片沿用原有使用者點擊才載入的面板播放器。
- 活動畫框目前為原創科學圖案示意，未將其當成真實活動照片；照片內容仍待後續提供公開授權素材。
- 榮譽牌上的主題為裝飾分類；真實得獎資料仍由既有 88 筆資料面板提供。

## 維護規則

簡單物品先用幾何建構，貼圖只用於平面印刷內容、材質及確實需要的插畫。不在貼圖中畫入物件側面、櫃框、窗框或固定視角陰影。尺寸／落位在模型中調整，構圖在相機設定中調整。

舊 `textures/`、`honors-camera.js`、`kiosk-camera.js` 與設計參考圖片保留供歷史追溯，現行 3D 場景不載入舊裁圖。維持按需渲染，靜態閱讀不持續繪製。
