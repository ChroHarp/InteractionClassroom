# 探索教室｜單一賽璐璐插畫風 3D 場景設計

## 風格與架構決策

捨棄從 2D 透視圖裁切或生成分散局部貼圖的做法，改為**統一溫暖賽璐璐插畫風真 3D（Unified Cel-Illustration 3D）**：所有牆面、家具、教具與展板皆使用同一套 3 階暖調色階光照（`MeshToonMaterial` + 階調 `DataTexture`）、深靛色墨線描邊（`addInkEdges`），以及高解析正面正交 Canvas 插畫貼圖，在任何鏡頭推近與視角切換角度下保持一致筆觸與完整幾何連續性。

  - 中前段（`z = -0.08 ~ +2.75`）：完整室內牆面與護牆板，懸掛 **`entry`（最新消息・軟木塞公佈欄，`z = 1.15`）**，擺脫畫面邊緣擁擠並可清楚辨識 4 張釘針公告。

  - 中景（`x = -0.15, z = -1.15`）：薄荷綠中空八角共學桌與 6 張木椅。
  - 前景（`x = 0.38, z = 1.95`）：白色六角數學探索桌與 6 張薄荷綠圓凳，桌面放置 3×3×3 魔術方塊、紫色四角錐、粉紅正十二面體、綠色三角板、幾何藍圖與直立 Λ 形金屬圓規。

## 材質與模型分工

| 模組 | 職責 |
| --- | --- |
| `scene-3d.js` | 相機控制、9 大熱點投影、按需渲染、橫式 Kiosk、講桌、共學桌、數學桌、黑板與課表框體 |
| `scene-environment.js` | 牆面護牆板、緊湊雙窗與戶外遠景、入口木門、連續星空壁畫、斜向窗光、天花格柵 |
| `scene-materials.js` | 統一賽璐璐調色盤、`MeshToonMaterial` 階調貼圖、共用墨線描邊 `addInkEdges`、地板／壁畫／黑板／課表／軟木公佈欄／活動框／橫式 Kiosk Canvas 繪製 |
| `scene-props.js` | 榮譽榜（銀灰溝槽板＋24 面木牌）、科學實驗台、三色創客櫃、數學桌教具（含直立圓規）、盆栽 |
| `materials/logo-2025.webp` | 橫式 Kiosk 螢幕左側 LOGO（轉檔保留完整比例） |
| `materials/activity-1..4.jpg` | 活動相片牆 4 張 16:9 活動照片 |
| `room/scene-fallback.jpg` | 同一個最終 3D 場景的無 UI 全景預覽截圖（`1280×720`） |

## 維護規則

- 維持按需渲染（Render-on-Demand），靜止閱讀不持續消耗 GPU；互動元素與非互動建築不共用可變材質實例，避免懸停高亮牽連他處。
- 物件尺寸與空間位置在模型模組內調整，各區與特寫構圖在 `scene-3d.js` 的 `VIEW_POSES` / `OBJECT_POSES` 調整。
- 舊 `textures/`、`honors-camera.js`、`kiosk-camera.js` 與早期 2D 設計圖保留供歷史追溯，現行 3D 場景不再載入。
